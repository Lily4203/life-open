# 支持与社群：钱从哪来，人从哪来

> 这一页回答两个问题：**怎么让别人给你打钱**，以及**怎么让别人找到你**。
> 先说结论：开源第一周，社群比打赏重要得多。没人知道你是谁的时候，打赏入口是个装饰。

---

## 一、git 收不到钱

GitHub / Gitee 是代码托管，不是支付平台。仓库里能放的是：

- 一个链接（点到爱发电/充电页）
- 一张二维码图片（微信/支付宝）
- 一个群号

钱最终还是走支付平台。所以"在 git 里加个收打赏的地方"准确说法是：**在仓库里加几个入口，指向真正能收钱的地方**。

---

## 二、四个渠道的真实门槛（2026-11 查的）

| 渠道 | 能不能用 | 门槛 | 抽成 |
|---|---|---|---|
| **GitHub Sponsors** | ❌ **中国大陆账号收不到** | 官方支持地区列表里有中国香港、中国澳门，**没有中国大陆**。收款要 Stripe，还得过美国的合规审查 | 0% |
| **爱发电 afdian.com** | ✅ 最省事 | 实名即可开；可以设"赞助"档位，也可以卖内容 | 约 5%（以官网为准） |
| **B站充电** | ✅ 但**有粉丝门槛** | 实名 + 30 天内有原创投稿 + 电磁力≥55 或 Lv3 + 信用分≥80 + **粉丝≥1000 或 播放≥10万** | 单次 50% / 包月 70% |
| **微信/支付宝收款码** | ✅ 零门槛 | 没有 | 0%，但没有账目、没有退款、二维码贴在公开仓库有被平台判定"导流"的风险 |

**所以现实路线是**：

```
第一个月：B 站发内容（充电开不了，因为粉丝不够）
       → 把 B 站号写进 README（这是社群入口，也是未来的打赏入口）
       → 有人问了，拉 QQ 群
第二个月：粉丝过 1000 → 开 B 站充电
       → 同时挂一个爱发电（不挑粉丝数，第一天就能用）
```

**不要第一天就挂收款码。** 一个刚发布、没有内容、没有社群的仓库挂收款码，
给人的第一印象是"这个人想要钱"，而不是"这个东西值得用"。

## 三、怎么填

```bash
cp config.example.json config.json
```

然后改 `config.json`：

```json
{
  "community": {
    "bilibili": { "name": "你的B站名", "url": "https://space.bilibili.com/1234567" },
    "qq": { "group": "123456789", "url": "", "note": "有问题、想说点什么，来这里" },
    "github": "https://github.com/你的名字/life"
  },
  "support": {
    "note": "她不要钱也能活着。这些是给「想让她活得好一点」的人准备的。",
    "links": [
      { "label": "爱发电", "url": "https://afdian.com/a/你的名字", "note": "请她喝一杯" }
    ]
  }
}
```

填完打开 `更新.html`，最下面「支持她继续活着」那一块就是它。

**留空的整块不显示**——没填 B 站就不会出现一个空的 B 站按钮。

### `config.json` 不进仓库

`.gitignore` 里挡着。原因：里面是你真实的账号和群号，
而**开源版交付的是一个空壳**——别人 clone 下来填自己的。

`config.example.json` 进仓库，它是格式说明。

## 四、比打赏更值钱的三件事

打赏是结果，不是原因。开源项目真正带来收入的顺序是：

1. **有人用**（star / clone / issue）。没人用的时候，打赏入口的转化率是 0。
2. **有人讨论**（群、issue、B站评论）。这是你唯一能听到"哪里不好用"的地方。
3. **有人愿意付钱**，因为他已经在用了。

所以 README 里第一屏该放的是：**这是什么、长什么样、怎么五分钟跑起来**。
打赏放最后一屏。

## 五、和许可的关系（这条容易踩）

`LICENSE` 是 **PolyForm Noncommercial 1.0.0**：别人可以自己用、自己改，
**不能拿它做生意**。

这带来一个副作用，得提前想清楚：

- 你收打赏 ✅ 可以（你是作者，许可是你给的）
- 别人拿你的代码开个收费服务 ❌ 不行（违反许可）
- 别人拿你的代码直播收礼物 ❌ 不行（那算商业使用）

如果你希望**别人也能拿去直播赚钱**（比如你想让生态长起来），就得换成 MIT 或 AGPL。
这两件事不能同时要：**"不许别人商用"和"欢迎别人拿去赚钱"是矛盾的**。

现在选的是前者。改主意的话，换 `LICENSE` 文件 + 改 `LICENSE-说明.md` 就够了，
代码一行不用动（因为许可不影响代码结构）。
