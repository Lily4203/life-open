# 她住在一间屋子里

一个 VRM 角色，站在一间有灯、有床、有窗帘、能走进去的房间里。她记得你说过的话，
有自己写下的待办，重启之后还接着做。没人理她的时候，她过日子。

> 开源版不带截图：房间里那个人是各人自己的。放一个 VRM 进来，这里就有画面了。
不是聊天框，不是桌宠，不是一场直播的布景。**是一个住处。**

---

## 和别的不一样在哪

同类项目做得比我们细得多：模型更强、动作更密、直播效果更炸。方向上有三处不同：

| | 直播型（Neuro 一类） | 桌面陪伴（AIRI 一类） | 这个 |
|---|---|---|---|
| **主体** | 一场节目 | 一个工具 | 一个人 |
| **世界** | 布景，镜头外不需要存在 | 一张立绘 + 透明背景 | 房间，她真的在里面 |
| **没人看的 30 分钟** | 待机、等指令 | 缩小到托盘 | 她过日子 |
| **重启之后** | 无状态 | 循环在内存，归零 | **记忆、议程、位置都还在** |
| **别人的位置** | 观众 | 使用者 | 邻居，能往这个世界里添东西 |

判据只有一条：**把镜头拿掉，项目还剩什么。**

## 她需要三样东西才能活

### 1. 一个模型（VRM）

开源版**不带模型**。不是忘了打包：第三方 VRM 的授权通常写死"禁止二次分发"，
而几十 MB 的二进制一旦进了 git 历史就永远删不掉。

把 `.vrm` 拖进页面就行：它先查骨骼、量身高，不合格当场说清缺什么
（不会让她进去之后动作全废），合格就存到 `assets/vrm/` 并登记进
`assets/characters.json`，下次打开还在。

从哪来一具身体、怎么挑、授权怎么看：**[建模/README.md](建模/README.md)**。

### 2. 一个密钥

`keys.json` 里填 `DEEPSEEK_API_KEY`。默认模型 `deepseek-chat`。

### 3. 一份记忆

```bash
cp -r data.example data
```

`data/identity.md` 决定她是谁。**这是整套东西里最难写的一份**，也是唯一没法自动生成的一份。
怎么写，看 [data.example/README.md](data.example/README.md)——里面有三条硬规矩和一个能直接用的骨架。

**行为不会写进记忆。** 每次动作只留一条人话回执进事件流（`events.jsonl`），不产生记忆条目；
`memories.json` 只有她自己 `remember` 才会长。写入时一次分好五个字段——谁说的、什么类型
（`said / did / memory / plan / event / error`）、有多重、从哪个入口来、从哪个装置来——
所以说话风格只从 `said` 取样，对话历史也只回放 `said`。开关灯二十次，她记得的事里一条都不会多；
一轮连做三步，动作回执在"刚刚发生的"里也只占一格，挤不掉你那句"早点睡"。
**这一条是"想和做分开"最大的回报，比动作本身值钱。**

## 五个设计决定

这几条不是风格偏好，每一条都对应一次真实的翻车。

**① 身体停下是反射，议程去留是她。**
你说"等一下"，她一秒内站住——这不需要她同意，一帧内完成。
但"原来那件事还做不做"由她下一轮自己决定，我们不替她划掉。
（早期让模型选择"要不要中止"，1.5 秒的尺度上物理不可行，实测每次都超时。）

**② 停在半路既不算成功也不算失败。**
动作结果有三种：`ok / partial / failed`。走到一半被叫停是 `partial`。
记成成功是当场穿帮，记成失败是慢性变笨。

**③ 动作只有 12 个，而且不允许带坐标。**
`go_to('床边')` 可以，`go_to(3.2, 0, -1.8)` 不行。大脑说"去哪"，不说"怎么走"。
坐标一旦进了提示词，她就从"想走过去"变成"在算路径"。

**④ 表现层不进大脑。**
大脑只说 `mood: happy`，抬哪只手、抬多高、先眨哪只眼，是身体自己的事。
手势也不是动作——**她点头是因为高兴，不是选了"叫点头的动作"。**

**⑤ 世界描述由世界自己写。**
`js/brain/world.mjs` 定形状（`pose / near / lights / at`），页面负责填。
提示词里那两行不是人手写的。

## 她能做什么

| 能做 | 说明 |
|---|---|
| 走路、坐下、躺下 | 13 个动作，走位到家具上用 `go_to`。走路是**真的迈腿**：左右反相摆、膝盖只在摆动相弯、落脚会往下沉一下 |
| 换一套动作 | `?anim=` 选一个 animator（`js/room/anim/`）。程序化那版不需要任何素材；接 VRMA/glTF 剪辑是另一个实现，形状一样 |
| 开灯关灯、拉窗帘 | 屋子里的开关是动词，不是背景 |
| 换衣服 | 三层：骨架 / 身体 / 穿戴，互不污染 |
| 接一个新平台 | `adapters/` 里扔一个 `.mjs` 就接上（QQ、弹幕、别的游戏），不碰核心代码；一条线坏了不拖垮别的 |
| 记得你说过的话 | 落盘，压缩，想不起来的进 `tombs` 而不是删掉 |
| 自己写待办 | `agenda.json`，重启还在 |
| 玩一局猜数字 | 游戏端口，和动作端口同一张表 |
| 听见你说话 | 浏览器自带的语音识别（Edge / Chrome），音频不出浏览器就变成字 |
| 看一眼你的屏幕 | 点「看」、或者她自己选 `look_screen`；出来只有一句话，图不落盘。要配一个多模态 key（智谱/通义/Gemini 都有免费额度） |
| 说话带表情和手势 | 八个身体能力，后端不会就降级成表情 |
| 说话像真人 | 默认用 edge 的神经音色（不是系统那个播报腔）；每句语速不完全一样、句尾会停一下；她高兴时快一点亮一点，难过时慢一点沉一点 |
| 说话不重复自己 | 每轮她能看见"最近几句 / 哪个开头用滥了 / 哪句撞了前面的"；和前面撞了会换一次说法（只换嘴，不换她要做的事）；没毛病时这一块根本不出现 |
| 知道一件事第几次了 | 同一盏灯十分钟里第四次被拨，她手上写的是"这是第 4 次：头一次在 2 分钟前"——不是第四次"第一次"。只给次数，不说"别再提了" |
| 外面能请她动手 | 服务端开了一个行动端口（`POST /api/act`）。DSH、脚本、别的 agent 可以**不经过她**直接派一个动作，成败原样回来；动作仍然过注册表（窗口、归属、三步上限）。接 DSH 见 **[docs/接入-dsh.md](docs/接入-dsh.md)** |
| 看完了可以不接 | 别人在说话、又没叫她，她可以不开口——空 `say` 是成立的一轮，不是失败；他本人说话、或者有人点她名字，就回。注意：不回省的是嘴，不是钱，一次模型调用照付 |

**不能做**

- **Live2D 跑不起来**：`vendor/live2d/` 是空的，Cubism Core 是专有 SDK 不能随仓库分发。
  代码路径是通的，你自己下 SDK 放进去就能用。
- **只有一个身体后端真的接上了**：vrm。live2d / mmd / spine / tachie 在能力表里有名字，没实现。
- **看不见副屏、看不见视频**：只截主屏，只看一帧。正在滚动的页面也只看得见那一瞬间。
- **不读屏幕上的字**：她看见"一个聊天窗口"，看不见里面是谁说了什么。
  这不是没做，是**故意不做**——要她读屏上的字是另一个功能，得重新过一遍隐私。
- **不能盈利直播（用示例模型的话）**：见上面授权那一段。

## 有新版本了怎么办

`更新.html` 是一个页面，回答三件事：我这份是哪一版、外面有没有新的、怎么换上去。

它**不会自己动手**。`version.json` 里的 `check.url` 填上仓库里这份文件的 raw 地址，
它就会去查；留空就只读本地、不联网。

四种状态都照实说，不含糊（**查不了**和**已经最新**是两件事）：

| 状态 | 意思 |
|---|---|
| 已经是最新 | 本地和远端同版本 |
| 外面有 0.2.0 | 有新版本，日志会直接显示在这一页 |
| 查不了：没联网 / 404 / 不是 JSON | **查不了不等于最新**——这两个必须分开说 |
| 你这份比发布版新 | 开发分支。这时候提示"有新版本"是错的 |

房间（`预览-66.html`）左下角只在新版本出现时亮一个小胶囊，点开就是这一页。

更新的时候**别覆盖 `data/`**（那是她的记忆，唯一不可再生的东西）、
`keys.json`、`config.json`、还有你自己放的模型。命令在 `更新.html` 里。
