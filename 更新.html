怎么换上去

推荐：把新版本拉到另一个目录，只把代码搬过来，不碰数据和配置。

# 1. 拉到旁边一个新目录（不要在你正在用的目录里 pull）
git clone <仓库地址> ../新版本

# 2. 把新代码盖到旧目录上，但排除这几样
rsync -a --exclude data/ --exclude keys.json --exclude config.json \
      --exclude assets/vrm/ --exclude vendor/live2d/ \
      ../新版本/ ./

# 3. 起服务，看首行有没有报缺块
node tools/serve.mjs

别覆盖 data/。里面是她的记忆和议程，是这整件事里唯一不可再生的东西。

别覆盖 keys.json / config.json。一个是密钥，一个是你填的社群和打赏地址。

模型和 Live2D 要自己放回去。它们不进仓库（授权和体积两个原因），更新完如果她不出来， 先看 assets/vrm/ 里还有没有你的模型。
