# 一件衣服怎么进来

> 三条路，从便宜到贵。**先选 overlay**——它只要一张图，今天就能穿上。
> 会建模的人再走 mesh / texture。

```
骨架 skeleton  ── 不动。换了它，整套穿戴都要重绑
  └ 身体 body  ── 皮肤、体型、脸。可以换，但通常整套换
      └ 穿戴 wear ── 发型 / 上衣 / 下装 / 鞋 / 饰品。这一层才是日常换的
```

**换装只动第三层。** 骨架和身体不跟着换，所以换一件衣服不需要重新导模型。

---

## 路一：有图就能生成（overlay）

### 你要准备什么

| 要什么 | 具体要求 |
|---|---|
| 一张图 | **去底的 PNG / WebP**（透明背景）。长边 ≥ 1024，别带投影、别带人、别带背景 |
| 穿在哪个槽 | `hair` / `top` / `bottom` / `shoes` / `accessory` 五选一（`body` 也行，但那是换身体） |
| 挂在哪根骨头 | 不知道就按下面的默认表；知道就填准确骨名 |
| 多大 | 宽 × 高，**单位是米**。默认表给了能用的起点 |
| 名字 / 作者 / 授权 | 名字会进提示词；授权决定别人能不能用 |

AI 画图也能用：提示词模板在同目录的 `生成提示词.txt`。
要求只有一句：**纯色（最好是纯白或纯绿）背景、正面、平铺、不要人、不要阴影。**

### 怎么生成

三种，任选：

1. **拖进工具页**：打开 `衣柜-导入.html`，把图拖进去。它会帮你抠掉纯色背景、让你选槽和骨头、拖滑块调大小，然后直接写进 `assets/wardrobe/items/<id>/`（Chrome/Edge 支持选文件夹；不支持就下载两个文件手动放）。
2. **命令行**：
   ```bash
   node tools/wardrobe/make.mjs --image 我的围巾.png --slot accessory --name 红围巾 \
     --bone chest --scale 0.30,0.153 --offset 0,0.17,0.055
   ```
   它会生成 `layer.png` + `manifest.json`，并自动加进 `assets/wardrobe/index.json`。
3. **手写**：复制 `_模板/manifest.json` 到 `assets/wardrobe/items/<id>/manifest.json`，改 6 个字段。

### 默认挂点（不知道填什么就用这个）

| 槽 | 骨名 | offset（米） | scale（米） |
|---|---|---|---|
| hair | head | 0, 0.10, 0.015 | 0.26, 0.24 |
| top | chest | 0, 0.10, 0.075 | 0.40, 0.34 |
| bottom | hips | 0, -0.04, 0.055 | 0.34, 0.30 |
| shoes | hips | 0, -0.45, 0.03 | 0.30, 0.14 |
| accessory | chest | 0, 0.12, 0.07 | 0.30, 0.16 |

**骨名**按 VRM Humanoid 的写法（小驼峰）：
`hips` `spine` `chest` `upperChest` `neck` `head`
`leftShoulder` `leftUpperArm` `leftLowerArm` `leftHand`
`rightShoulder` `rightUpperArm` `rightLowerArm` `rightHand`
`leftUpperLeg` `leftLowerLeg` `leftFoot` `rightUpperLeg` `rightLowerLeg` `rightFoot`

### 目录长什么样

```
assets/wardrobe/
  index.json                       ← 目录：加了哪几件
  items/
    scarf-red/
      manifest.json                ← 这件是什么、挂哪、多大
      layer.png                    ← 你的图（去底）
    vest-cream/
      manifest.json
      layer.png
```

`index.json` 里加一行就多一件：

```json
{ "items": ["items/scarf-red/manifest.json", "items/vest-cream/manifest.json"] }
```

### 验收

- 打开 66，控制台：`__WARDROBE.list()` 能看到它；`__WARDROBE.equip('scarf-red')` 穿上。
- 或者直接跟她说「把围巾戴上」——前提是她看得到这件（`entities()` 会把可穿的列进提示词）。
- 位置不对，就改 `anchor.offset` / `anchor.scale`，不用重新导图。

## 路二：会建模的人（mesh）

### 你要准备什么

| 要什么 | 具体要求 |
|---|---|
| 网格 | `.glb`（推荐）或 `.gltf` + `.bin`。单位米，原点在骨架原点；如果是单根骨头上的硬物，原点放在挂点 |
| 蒙皮 | 自带蒙皮就 `skinning: "auto"`；只是一件硬物就 `skinning: "rigid"`，整件跟着 `anchor.bone` 动 |
| 面数 | 建议 < 30k。衣服不是主角，别把预算全花在这 |
| 材质 | 名字用英文；贴图打包进 GLB 最省事 |
| 不带动画 | **动作由身体那侧放**，衣服只跟着动。带动画会和身体抢 |
| 授权 / 作者 | 必填 |

### 怎么进来

复制 `_模板/manifest-3D.json` 到 `assets/wardrobe/items/<id>/manifest.json`，把 `mode` 改成 `mesh`，`files.mesh` 指向你的 GLB，加进 `index.json`。

### 骨架必须对得上

`requires.skeleton` 写的是**这副骨架的 id**（现在是 `fish-vrm`）。
骨架不同（VRM 0.x / 1.0、MMD、Live2D 的 rig 都不同），同一件网格套不上去。
对不上时衣柜会**拒绝穿上并说明原因**，不会硬套出一个扭曲的东西。

## 路三：只换贴图（texture）

适合"衣服形状不变，只换花色/颜色"。

- 一张 PNG，尺寸跟原贴图一致（常见 2048×2048）。
- UV 必须是目标材质的 UV，不是你随手画的。
- manifest 里 `mode: "texture"`，`files.texture` 指向图，`target` 写材质名（比如 `Body`、`Cloth_A`）。

这条最省资源，但对"换一件不同款式的衣服"没用——那要 mesh 或 overlay。

---

## 六条规矩（都是踩过的）

1. **图必须去底。** 带白底的 JPG 贴上去是一块白方块。工具页能抠纯色底，复杂背景请自己抠。
2. **单位是米。** 填 300 会得到一栋楼那么大的围巾。
3. **一个槽一件。** 上衣同时只能一件；饰品最多 4 件。想叠穿就把两件画在同一张图里。
4. **骨架换不得。** 换骨架 = 换身体格式，穿戴的 `requires` 会全部失效。这是设计，不是 bug。
5. **授权写清楚。** 没有 license 的件，别人不敢用，也不敢分发。
6. **别把话写进衣服。** 衣服只描述"穿什么"；她要不要穿、什么时候穿，是她自己的决定。

---

## 现在这套的边界（写清楚，免得误会）

- **overlay 是一张片**：正面看是衣服，侧面看会薄。它解决"今天就能换"，不解决"布料解算"。
- **mesh 需要绑定**：不蒙皮的网格只能整件跟着一根骨头动，弯胳膊时不会跟着弯。
- **2D 后端（Live2D/立绘）**：目前只认 overlay 的正面层；`cover: ["front"]`。侧身、背面要另画差分。
- **没有自动试衣间**：不会从一张真人照片自动抠出衣服并绑骨。工具页只做"抠纯色底 + 摆位置"。
